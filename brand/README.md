# WITUS 로고 파일

**저장소 밖으로 나가는 용도**다 — 명함·제안서·계약서·단말기 스티커·협력사 전달.
웹사이트가 쓰는 파일은 `app/icon.svg` · `app/apple-icon.png` · `app/opengraph-image.png` 다.

## ⚠️ 손으로 고치지 않는다

전부 **생성물**이다. 도형은 `content/brand.ts` 의 `SHIELD_PATH` 한 곳에만 있다.

```bash
node scripts/generate-brand-assets.mjs   # 사이트 아이콘 + 이 폴더를 함께 다시 만든다
```

## 파일

| 파일 | 용도 |
|---|---|
| `witus-symbol-ink` | **기본.** 흰 배경 문서·제안서 |
| `witus-symbol-black` | **1도 인쇄** — 계약서·팩스·실크스크린 |
| `witus-symbol-white` | 어두운 배경 |
| `witus-symbol-navy` | 네이비 단색 |
| `witus-symbol-gold` | **어두운 배경에만.** 흰 배경 대비 2.25:1 로 접근성 미달 |
| `witus-badge-navy-gold` | 아이덴티티 배지 — 앱 아이콘·SNS 프로필 |

`.svg` 는 무한 확대(인쇄용), `.png` 는 높이 1024px 투명 배경(오피스 문서용).

## 워드마크가 없는 이유

사이트의 `WITUS` 글자는 **시스템 폰트로 실시간 렌더**된다. 브랜드 서체(Inter/Manrope)
파일이 저장소에 없어 **심볼만** 만들었다. 워드마크 락업이 필요하면 폰트 파일을
커밋하고 이 스크립트에 텍스트 렌더를 추가한다 — 웹·임베딩 라이선스를 먼저 확인할 것.

## 쓸 때 지킬 것

- **골드를 흰 배경의 작은 크기에 쓰지 않는다.** 대비 2.25:1 이라 안 읽힌다.
- **사선 2개가 뚫린 형태**가 맞다. 통짜 방패로 보이면 잘못 변환된 것이다.
- 심볼 주위 여백은 방패 높이의 **1/4 이상** 둔다.
